# 취약 파트 컨닝페이퍼 (10월 26일)

## 식물 (첫 시도 50%)

| 항목             | 내용                                                  |
| -------------- | --------------------------------------------------- |
| **세대교번 흐름**    | 포자체(2n) →감수분열→ 포자(n) → 배우체(n) →**체세포분열**→ 배우자(n)    |
| **속씨식물 핵상**    | 배젖 3n > 접합자 = 대포자낭 2n > 소포자 = 알세포 n                 |
| **열매가 되는 것**   | 씨방 (배젖 X)                                           |
| **겉씨식물 종자**    | 씨방 없음 → 밑씨가 드러나 있음                                  |
| **1기 생장**      | 정단분열조직 → 길이 생장                                      |
| **2기 생장**      | 관다발형성층·코르크형성층 → 부피 생장 (잎에서는 안 일어남)                  |
| **아포플라스트**     | 세포벽·세포간극·물관/헛물관 (원형질연락사는 심플라스트)                     |
| **식물 표피**      | 세포간극 없음                                             |
| **체관요소**       | 살아 있는 세포, 세포벽 O, 색소체 X                              |
| **물 상승 원동력**   | 증산(증발)·응집력(수소결합)·근압(삼투압). 물의 팽창 X                   |
| **저온 적응**      | 막 지질 불포화도↑, 세포 내 용질↑ (어는점↓)                         |
| **에틸렌**        | 기체 호르몬, 노쇠·과일 숙성                                    |
| **사이토키닌**      | 세포분열·측아 생장↑, 노화 지연 (숙성 X)                           |
| **앱시스산**       | 수분 스트레스 → 기공 닫음, 휴면                                 |
| **옥신 이동**      | 정단→기저 극성수송. 세포벽(산성)에서 중성형으로 들어와 세포질(중성)에서 이온화형으로 갇힘 |
| **피토크롬**       | 적색광 → Pfr(활성) / 근적외선 → Pr(불활성)                      |
| **단일식물 개화**    | 암기 길이로 판단. 암기 중 적색광 섬광 → 개화 X                       |
| **외떡잎 vs 쌍떡잎** | 외떡잎: 관다발 흩어짐·나란히맥·수염뿌리 / 쌍떡잎: 관다발 고리·그물맥·원뿌리        |

| ------------------ | ----------------------------------------------------- |

| **LH 차단 시**        | 배란 X                                                  |

| **정자 저장**          | 세정관에서 형성 → 부정소에서 성숙·저장                                |
| **외배엽**            | 표피·신경계·눈 수정체                                          |

| **내배엽**            | 소화관·호흡계 내벽, 간·이자                                      |

| **배외막**            | 영양아층 → 융모막(태반) / 난황낭 = 최초 혈구 생성 / 양막 = 양수·충격 흡수       |
| **난할 특징**          | 세포 수↑·크기↓·전체 크기 그대로, G1·G2 거의 없음, 새 전사 거의 X → 포배      |
| **동물에만 있는 현상**     | 낭배형성                                                  |
| **성게 수정 순서**       | 첨체반응 → 탈분극(빠른 다수정 방지) → **Ca²⁺↑** → 피층반응 → 수정막(느린 방지) |
| **성게·포유류 공통점**     | 첨체반응 (포유류는 투명대에서)                                     |
| **배란된 난자**         | 감수 2분열 중기 정지, 투명대·난구세포로 둘러싸임                          |
| **신경관 / 신경릉 / 척삭** | 중추신경계 / 말초신경(신경절·감각·교감) / 추간판 수핵                      |
