## 배외막 → 이루는 배엽

| 항목 | 내용 |
| --- | --- |
| **양막** | 외배엽 + 중배엽 |
| **융모막** | 외배엽 + 중배엽 |
| **요막** | 중배엽 + 내배엽 |
| **난황막(난황낭)** | 배외중배엽 + 장쪽 내배엽 |

## 배외막 → 하는 일

| 항목 | 내용 |
| --- | --- |
| **양막이 하는 일** | 태아를 둘러싸는 보호막 |
| **융모막이 하는 일** | 태반의 주요 부분, 모체와 태아 사이 물질 교환 |
| **요막이 하는 일** | 대사 노폐물 저장, 태반 형성에 기여 |
| **난황막이 하는 일** | 초기 영양 공급, 혈구·혈관 형성에 참여 |

## 상배엽·하배엽

| 항목 | 내용 |
| --- | --- |
| **외배엽·중배엽·내배엽이 나오는 층** | 상배엽(epiblast) |
| **양막·융모막·요막이 나오는 층** | 상배엽(epiblast) |
| **난황막(난황낭)이 나오는 층** | 하배엽(hypoblast) |

## 외우는 요령

| 항목 | 내용 |
| --- | --- |
| **결합조직의 배엽 (예외 포함)** | 중배엽. 단 **치아·머리뼈**는 외배엽 |
| **부신수질이 외배엽인 이유** | 신경조직 출신이라서 |
| **문제에 기관계 이름이 나오면** | 그 기관계에 속한 **상피조직**을 묻는 것 |
| **효율적으로 외우는 법** | 상피조직만 따로 외우고, 신경조직(외배엽)·근육·결합조직(중배엽)은 통으로 |
